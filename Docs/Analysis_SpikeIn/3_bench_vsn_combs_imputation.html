Funcion de nombrar

making_names <- function(combin){
  if(combin$imp_meth ==  "combo"){
    paste(combin$norm_meth, combin$mar_meth, combin$mnar_meth, sep="_")
  }
  #Non imputation
  else if(combin$imp_meth == "none"){
    paste(combin$norm_meth, "none", sep="_")
  }
  # SoftHybrid method
  else if(combin$imp_meth == "softHybrid"){
    paste(combin$norm_meth, "softHybrid", combin$mar_meth, combin$mnar_meth, sep="_")
  }
  #limpa method
  else if(combin$imp_meth == "limpa"){
    paste(combin$norm_meth, combin$imp_meth, sep = "_")
  }
  else {
    paste(combin$norm_meth, combin$imp_meth, sep="_")
  } 
}

Gráficos y comparaciones

Según la gráfica superior Figure 1, donde se muestra la posición según las métricas OpDEA, al igual que en la ?@fig-ext-rank-bars, el mejor método de imputación de valores cuando la normalización se realiza mediante vsn_combs, es la combinación de Impseq y min. El método Impseq se usa para imputar valores en los valores ausentes aleatorios mientras que el método min se utiliza en los valores ausentes no aleatorios.

Al analizar las curvas ROC para cada comparación, el método de imputacion para valores ausentes aleatorios bpca tambien tiende a tomar las posiciones más altas alternando el método de imputacion de valores ausentes no aleatorios entre min y halfmin. Dependiendo de la diferencia real entre las muestras (Figure 3). Como ocurre cuando se imputan valores con el método Rlr.

De la misma manera que en el caso de normalización con Rlr los métodos de imputación de valores MNAR que se muestran como los más adecuados, son min, halfmin, zero y el método softHybrid. Este último no se evalua dadas las limitaciones de espacio.
